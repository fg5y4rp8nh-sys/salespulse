# SalesPulse

B2B-дашборд аналитики продаж с AI-инсайтами. Компания загружает продажи в CSV → получает
дашборд с графиками → Gemini объясняет человеческим языком, что происходит с бизнесом и что делать.

**Аудитория:** Head of Sales в компаниях 20–200 чел. (B2B-опт, SaaS, дистрибьюторы, digital-агентства).
Их боль — 8–15 ч/нед на ручное сведение Excel. SalesPulse: загрузил CSV → за 30 сек видишь
что упало и почему.

**Ключевой оффер:** не просто «выручка упала на 20%», а *почему* именно и *что делать*
(с указанием менеджера/региона/пайплайна).

## Функционал (6 фич + демо)

1. **Загрузка CSV** — продажи (дата, менеджер, регион, сумма, статус) → парсинг → база.
2. **Главный дашборд** — 4 карточки (выручка +/-% к прошлому периоду, кол-во сделок, средний
   чек, конверсия) + 3 графика: выручка по дням (линия), топ-5 менеджеров (столбики),
   по регионам (пирог).
3. **Воронка продаж** — Лид → Квалификация → Предложение → Переговоры → Закрытие.
4. **🌟 AI-инсайты (главная фича)** — Gemini выдаёт 3–5 карточек с объяснением + рекомендацией.
5. **Фильтры** — по датам (7/30/90 дней/свой), менеджеру, региону, статусу; пересчёт на лету.
6. **Экспорт в PDF** — «Скачать отчёт» с графиками и инсайтами (jsPDF).
7. **Демо-режим** — «Try Demo» без регистрации: фейковые данные вымышленной компании.

## Переменные окружения

Реальные значения хранятся в `.env.local` (в git НЕ попадает). Здесь — только имена:

- `DATABASE_URL` — строка подключения к Neon (PostgreSQL)
- `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` — публичный ключ Clerk
- `CLERK_SECRET_KEY` — секретный ключ Clerk
- `GEMINI_API_KEY` — ключ Google Gemini

Эти же переменные нужно добавить в настройки проекта на Vercel (Settings → Environment Variables).

### Ключевые файлы
- `lib/analytics.ts` — вся аналитика (метрики, графики, воронка) из массива сделок.

  `actions.ts` (add/delete/reset), `ExportButton.tsx`, `ResetButton.tsx`.
